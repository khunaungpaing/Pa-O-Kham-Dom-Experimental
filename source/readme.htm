Pa-O Kham Dom Experimental

ဤ package သည် ပအိုဝ်းစာရိုက်ရန် Windows နှင့် macOS Keyman ကီးဘုတ်၊ KhamThaton-Exp Regular နှင့် Bold ဖောင့်များကို ထည့်သွင်းရန် ဖြစ်သည်။

ရည်ရွယ်ချက်

ဤကီးဘုတ်နှင့်ဖောင့်ကို ပအိုဝ်းစာရိုက်ရန် အဓိကရည်ရွယ်ထားသည်။ ASCII/Win font အဟောင်းဖြင့် စာရိုက်ရာတွင် ပါဌ်ဆင့်စာလုံးများအတွက် `Alt` နှင့်တွဲနှိပ်ရခြင်း၊ စာရိုက်ရခက်ခဲခြင်းတို့ကို လွယ်ကူစေရန် Keyman keyboard mapping နှင့် OpenType font ဖြင့် ပြုလုပ်ထားခြင်းဖြစ်သည်။

အရေးကြီးသော အသိပေးချက်

ပအိုဝ်းနံပါတ်များသည် တရားဝင် Unicode ဖြစ်သည်။ Kham Dom အတွက် လိုအပ်နေသေးသော ပုံစံသုံးလုံးကိုသာ U+103E (`ှ`)၊ U+1082(`ႂ`) နှင့် U+108F(`ႏ`) ဖြင့် ယာယီအစားထိုးထားသည်။ Font ကို ပုံမှန်အသုံးပြုလျှင် ပအိုဝ်းစာလုံးများဖြစ်သော ထိုမ်းပါ၊ လပန်နှင့် ခမ်းသိုမ်ဖြိုင် ပုံစံများကို ပြသမည်။

ss01 အကြောင်း — ss01 ကို ဖွင့်လျှင် ပုံမှန် ပအိုဝ်းစာပုံစံမဟုတ်ဘဲ အစားထိုးယူထားသော မူရင်း glyph ပုံစံကို ပြသည်။ ပုံမှန် ပအိုဝ်းစာရိုက်ရန် ss01 ကို ဖွင့်ရန် မလိုပါ။

သတိပြုရန်
