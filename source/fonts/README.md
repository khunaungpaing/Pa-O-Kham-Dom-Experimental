# တွဲဖက်ဖောင့် အချက်အလက်

ဤ folder ထဲရှိ Kham Dom တွဲဖက်ဖောင့်မှာ—

```text
source/fonts/KhamThaton-Exp-Regular-0.2.ttf
source/fonts/KhamThaton-Exp-Bold-0.2.ttf
```

- ဖောင့်မိသားစုအမည် — `KhamThaton-Exp`
- ဖောင့်အမည်အပြည့်အစုံ — `KhamThaton-Exp Regular` နှင့် `KhamThaton-Exp Bold`
- ပါဝင်သော style — Regular နှင့် Bold
- လိုအပ်သော stylistic set — `ss01`

ပအိုဝ်းနံပါတ်များသည် တရားဝင် Unicode ဖြစ်သည်။ တရားဝင် Unicode code point
မရသေးသော Kham Dom ပုံစံ သုံးလုံးအတွက် U+103E (`ှ`)၊ U+105E(`ၞ`) နှင့် U+108F(`ႏ`) ကို ယာယီအစားထိုးအသုံးပြုထားသည်။ Font ကို ပုံမှန်အသုံးပြုလျှင် ပအိုဝ်းပုံသဏ္ဍာန်ကို
ပြသပြီး `ss01` ဖွင့်လျှင် အစားထိုးယူထားသော မူရင်း glyph ပုံစံကို ပြသမည်။

`source/pa_o_kham_dom.kps` တွင် ဤ font ကို package နှင့်အတူ install လုပ်ရန်၊
on-screen keyboard font နှင့် keyboard display font အဖြစ်အသုံးပြုရန်
ချိတ်ဆက်ထားပြီးဖြစ်သည်။
