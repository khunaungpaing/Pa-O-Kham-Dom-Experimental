Pa-O Kham Dom Experimental

ကီးဘုတ် package ကို install လုပ်ပြီးပါပြီ။ အသုံးပြုနိုင်ပါပြီ။

အရေးကြီးသည်။ ပအိုဝ်းနံပါတ်များသည် တရားဝင် Unicode ဖြစ်သည်။ Kham Dom အတွက် လိုအပ်နေသေးသော ပုံစံသုံးလုံးကိုသာ U+103E (`ှ`)၊ U+1082(`ႂ`) နှင့် U+108F(`ႏ`) ဖြင့် ယာယီအစားထိုးထားသည်။ Font ကို ပုံမှန်အသုံးပြုလျှင် ထိုမ်းပါ၊ လပန်နှင့် ခမ်းသိုမ်ဖြိုင် ပုံစံများကို မှန်မှန်ကန်ကန်ပြသပေးလိမ့်မည်။

သတိပြုရန်

ဤကီးဘုတ်သည် standard version မဟုတ်ပါ။ Project ပိုင်ရှင်၏ ခွင့်ပြုချက်မရှိဘဲ official Keyman catalog သို့ upload သို့မဟုတ် publish မလုပ်ပါနှင့်။

နောင်တွင် လိုအပ်နေသော အက္ခရာသုံးလုံးအတွက် မှန်ကန်သော Unicode code point များ ရရှိလာပါက converter App ကို ပြန်ထုတ်ပေးပါဦးမည်။
